# Parts of others

## Fonts

The page is set in two fonts. `build.js` builds them into the page from the folder `fonts`.

| Font | Copyright | Licence |
|---|---|---|
| Geist | Copyright 2024 The Geist Project Authors (https://github.com/vercel/geist-font) | SIL Open Font License 1.1, see `fonts/OFL-Geist.txt` |
| STIX Two Text | Copyright 2001-2021 The STIX Fonts Project Authors (https://github.com/stipub/stixfonts) | SIL Open Font License 1.1, see `fonts/OFL-STIX-Two-Text.txt` |

The font files are the subsets Latin, Latin Extended and, for STIX Two Text, Greek, as packed by the Fontsource project (https://fontsource.org).

## Section properties

The dimensions, areas and second moments of area of the profiles (IPE 200 to IPE 400, HEB 200, HEB 300) are the values of the sales programme for sections of ArcelorMittal (2023). The section modulus and the mass are worked out from them on the page.

## Nothing else

The page uses no library. The checks use Node.js, Python, NumPy and Playwright, which are not part of this package.
